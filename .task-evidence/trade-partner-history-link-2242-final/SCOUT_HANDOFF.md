## What changed

Recommended Trades and Evaluate have one compact “See franchise trade history” link to the exact other franchise in the current league. It opens the existing descriptive completed-trade section with its supporting transactions and original history qualifications. Unknown/ambiguous/self/foreign partners have no link. The link is not an authorization capability; the server and navigation context reauthorize account/league scope.

Recommended retains the clicked exact offer as a bounded existing preview. It does not adopt the offer or overwrite the draft. Evaluate preserves its current draft and assessment. Existing mode, strategy, asset search/position filters, search options and return state remain scoped to the account, league, franchise and tab. Retained evidence remains not revalidated; opening history never makes a prior assessment current.
