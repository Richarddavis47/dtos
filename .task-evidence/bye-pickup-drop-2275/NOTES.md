# Bye pickup add/drop preview scope

The existing shortlist proves that adding a player can cover one target-week slot. On a full active roster, dropping a player can take away that cover or open a different slot. The preview accepts one explicitly selected on-roster active player and one still-unrostered shortlisted candidate. It recomputes one legal lineup using the same matching and availability rules and the target-week evidence. The prepared comparison basis is stored once per week and roster. A click never starts a Market build, asks Sleeper to fetch data, or changes the roster.

The outgoing value is read only from the selected league’s compatible, already admitted Market publication. The preview leaves the price unavailable when that evidence is missing. It reports legal lineup coverage separately from the outgoing price and from the pickup’s original target-week Sleeper projection.

The add/drop has no net effect on active roster occupancy. If returning a confirmed ineligible player from IR would exceed capacity after the swap, the card gives the remaining number of active spots. The lineup preview includes the two selected moves without assuming an additional IR move. Sleeper controls locks, adds, drops and waiver claims.

The first focused attempt hit a browser navigation race before reading the dropdown. The test now waits for the rendered control and exact comparison URL. The original attempt is preserved separately. Local responsive evidence uses deterministic test leagues and Chromium.
