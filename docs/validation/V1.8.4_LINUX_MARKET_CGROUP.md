# DTOS v1.8.4 Linux Asset Market cgroup validation

The temporary GitHub-hosted Ubuntu validation run completed successfully against commit
`84b8747008233b66b741edb52cd4aea700cb761b`.

The measured container used one worker, a Docker-enforced 2 GiB memory limit, a generated
sanitized fixture with 12,322 players, 120 unique draft picks, 30,726 historical records,
and the canonical `completed_with_pending` historical state of 5/6 seasons. No production
credentials, provider tokens, production payloads, or production databases were used.
