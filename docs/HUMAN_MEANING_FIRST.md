# Human Meaning First

DTOS presents decision meaning before implementation details.

- Pages lead with names, outcomes, ranks, confidence, evidence, and availability.
- Missing data explains what is missing and never converts missing evidence to zero.
- IDs, generations, model versions, and provenance remain available under collapsed **Technical Details**.
- Historical ranks come only from verified historical evidence; current values are never backdated.
- Provider values remain separate from DTOS intrinsic and league-adjusted values.
- Presentation is deterministic, read-only, and never synchronizes providers or rebuilds canonical state.

Machine-oriented API fields remain stable. This policy governs normal human-facing HTML and presentation inspection artifacts.
