# Adjust Offer / Bad-Trade Repair acceptance ledger

Implementation uses the existing proposal and shared evaluator, not an adjustment
grade. Session instructions never change canonical values, grades or ownership.

## Established constraint inventory

| Constraint | Supported meaning | Focused boundary |
| --- | --- | --- |
| Keep player | Exclude named outgoing player before construction | Proven positive replacement; no retained outgoing copy |
| Do not trade picks | Protect every owned outgoing pick | Proven; no-result if no credible pick-free package |
| Replace asset | Exclude the named identity, preserve target unless explicitly permitted otherwise | Proven positive replacement and distinct named clauses |
| Use WRs | Restrict outgoing player construction/replacement pool to WRs | Proven before generator, not a post-search preference |
| Add pick | Add a newly included owned exact pick with supported acquisition evidence | Proven positive priced-pick fixture; missing quote remains unsupported |
| Get player back | Add another owned return player without dropping original targets | Proven positive target-set preservation |
| Younger | Lower average known age of received players; all relevant player ages required | Proven; quality still requires shared gate; not a longevity forecast |
| Win-now | Improve supported current/next-N effects without comparable near-term, ROS, playoff or reserve-coverage regression | Proven horizon regression rejection; unsupported later horizons reported |
| Cheaper | Strictly lower fully supported outgoing acquisition cost | Proven price-total comparison; not asset-count grading |
| Expand | Larger package with actual additional player contribution and shared bilateral qualification | Proven; noncontributing stuffing does not qualify |

Natural-language support is limited to established commands and exact displayed
asset names. Unknown references are not interpreted as arbitrary intent. No
permanent strategy preference or general natural-language agent is introduced.
No promise of a real qualifying offer for every command is made.

Keep+replace the same identity, no-picks+add-outgoing-pick, protected Shop objective
and excluded preserved targets report explicit constraint conflict. Shop preserves
its outgoing asset; ordinary repair preserves all original return targets, with
additional returns allowed. Explicit Alternative Target is the only target-changing
mode. Constraints are request-local; fresh manual/workflow sessions remain clean.

## Repair semantics

Make This Trade Work selects the smallest changed qualifying package, with Market
distance as a secondary construction preference. It does not reinterpret quality.
Alternative Construction requires material identity/concept change; swapping
nominal same-year/round/range/slot pick sweeteners is not sufficient.
Alternative Target is withheld when the original or a target-preserving repair is
credible. A replacement must preserve requested player role/position or pick
year/round scope, and pass the shared evaluator. That bounded scope is explicitly
reported, not a claim of inferred hidden manager intent.

No credible adjustment/repair is valid. Three options are never forced.

## Evidence and performance

The original proposal and every assessed candidate use the same canonical five-origin
evaluation contract. One pinned projection reader and prepared pre-trade evidence
are reused per request. Post-trade effects remain package-specific. Start/end input
guards reject ownership/generation/league changes. No source preparation, production
mutation or durable history is performed by adjustment search.

Construction stays bounded by the established nearby-candidate search. Instrumentation
reports constructed/evaluated counts, projection-week reads, construction, shared
evaluation and total time. Real diagnostic panels are explicitly constrained subsets,
not exhaustive recall or final production latency proof.
