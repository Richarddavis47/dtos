# Relative Custom valuation — build 2219

## Approved contract

Absolute (`personal-current-market-slot-curve-v1`) remains the default for schema-1 documents, with its original full-cohort extremal completion formula and exact own-price gate unchanged. Relative (`personal-relative-priced-order-v1`) is optional: filter saved order S to compatible eligible priced members P from one admitted publication; sort those members' neutral quotes descending into D; assign q(P[j])=D[j]. Missing rows remain visible at their saved global positions and receive no personal amount or price slot. New unranked assets never silently enter the saved cohort. Zero is a supported number. Tiers and flags do not change the curve.

At fixed evidence, upward moves are weakly monotonic. Moving across only unsupported rows leaves amounts unchanged. Priced-pool totals are conserved; complete coverage equals Absolute, and every original exact partial value is preserved. Quote returns/removals can reprice other supported assets: this is a disclosed new contract, not Market recovery or NFL performance evidence.

## Scoped opt-in and publication review

The existing private CSRF-protected My DTOS command route supports read-only method preview and explicit confirmation. A stateless digest binds target method, full ranking document/revision, publication, scope and live session. The apply command recomputes and compares it, then uses the existing source lock, scope/session checks and transactional revision CAS. Opening a preview never writes. There is no automatic switch. Neutral/Custom mode is independent of the selected Custom method.

Schema 2 adds only a validated versioned method ID and a bounded review reference (generation, timestamp, priced saved IDs and value digest). It contains no stored price map or provider history. Read-only publication changes never update user revisions. Notices compare eligible identity membership with the last explicitly confirmed review, not an invented previous-price history. Current method comparison is available through Preview; previous exact amounts cannot be reconstructed after publication retirement. Review confirmation is explicit and increments preference revision.

Reversal previews Absolute and saves an explicit new revision; it never resets order, tiers, flags, original baseline or identity. Deliberate Restart remains separate and retains Relative when selected. Schema-1 documents are not migrated on reads or ordinary edits. Unknown method/schema versions fail closed. A technical rollback must use method-aware code or first obtain deliberate manager reversals; old binaries cannot safely interpret schema 2 and must not silently treat it as schema 1.

## Shared Trade and resources

All Custom consumers use the existing shared personal context and revision/publication admission: Builder, Calculator/Evaluate, Trade For, Shop, Recommended, Assist/Adjust, Balance, alternatives and previews. Method/revision travel with results; method changes invalidate stale results without replacing exact packages. Neutral fairness, counterparties, projections, legal lineups, ownership, roster capacity, severe-overpay and historical qualifications remain unchanged. More numerical availability is not a promise of more qualified offers.

Preview examples are at most two same-snapshot owned-versus-counterparty packages, clearly labeled arithmetic only. They call no discovery or solver and do not create a workspace/offer. Reads use the existing bounded Market directory, sort at most 10,000 assets, and do not add polling or provider preparation. Existing 512 KiB document limit applies; oversized opt-ins fail without truncating intent. No analytical warehouse, paid infrastructure or new cache.

## Evidence scope

Tests use disposable accounts and prepared publications. The 628/589/39 control is a synthetic canonical-scale cohort with the same 52-price tie geometry, producing 12 Absolute and 589 Relative values. It is not a live source completeness claim. Responsive controlled Chromium is not physical iPhone/Safari acceptance. Original failures and retries are preserved outside the source tree. Full canonical/hosted outcomes and production identity must be recorded separately; they are not assumed by this document.
