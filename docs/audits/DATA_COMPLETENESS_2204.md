## The exact partial rule

For a cohort of N assets with M unsupported current inputs, retain N saved positions. Build two internal extremal completions using the existing canonical 0–1000 domain: all missing inputs at the lower endpoint and all at the upper endpoint. Order statistics are monotone in every input. A slot identical in both completions is therefore identical for every possible compatible completion. Only a currently compatible priced asset at such a slot receives that exact personal value. The endpoint completions are bounds, never prices assigned to unsupported assets. Unsupported assets never receive a value even when their own slot happens to be determinate.

Example: known prices 800, 500, 500, 500, 300 and one missing input give lower slots [800,500,500,500,300,0] and upper slots [1000,800,500,500,500,300]. Original positions three and four are exactly 500; their positions are not compressed or reassigned. With known prices 800 and 300 plus one missing input, no slot is determined. The original guard remains necessary in that case. This is an exact partial application of the existing function, not a fallback valuation model.
