# Next observed trade packages

The original timeline showed later trade links, exact pick conversions and independent current-owner observations. It did not show a later deal’s complete consideration beside the original receipt.

## Admission

The added read model follows one original receipt, optionally through one exact observed draft conversion, to its recipient’s first supported outgoing completed trade. It uses the existing canonical graph, source-season chain, timestamp normalization, directed-consideration parser and generation cache. A source timestamp is an occurrence observation, never a reconstructed trade-time manager identity. Equal or overlapping times do not establish order. Dates are compared as UTC instants, including fractional seconds.

A release, unexplained acquisition, different sender, uncertain conversion, conflicting completed records, missing clocks or exceeded bounds withholds attribution. It does not resume after reacquisition. Pending/rejected/cancelled/failed events are excluded. Current ownership and roster snapshots do not establish uninterrupted historical ownership. Missing periods may hide transitions; the presentation says **observed** continuation, never exhaustive lineage.

Contradictory completed endpoint rows are qualified inside each source publication before existing key collapse. Exact semantic duplicates collapse. A legitimate new authoritative publication can supersede retained data; old and new generations are not treated as concurrent conflicting observations. A compact legacy checkpoint cannot recover source variants already discarded before this qualification existed.

## Presentation

A later transaction is shown once even if it contains several original receipts. Every supported directed leg and counterparty remains attached to the package. The followed outgoing asset is distinguished from other outgoing consideration. Partial consideration preserves supported legs while withholding a full-return claim. Exact pick identities retain year, round and original franchise; a drafted player never substitutes for the historical pick in an earlier package.

There is no value, production, benefit, winner, intention or championship-credit allocation. Historical FOIS grades remain RETAINED / NOT REVALIDATED. Season-observed manager names remain separate from verified trade-time decision makers.

## Bounds and lifecycle

At most 40 original assets, 100 eligible event groups across branches, one conversion and one subsequent exchange per branch; at most 40 movements/participants in a displayed package. No recursive traversal of returned consideration. Packages share one request-local deduplication map and the existing bounded generation cache. Source changes during assembly withhold packages and prevent caching; a held graph cannot reuse a package from a superseded generation. No provider acquisition, synchronization, projection calculation, Trade evaluation or heavyweight lease is added to rendering or disclosure expansion. The existing 2 GiB cap and all admission/reservation policies remain unchanged.
