The small Home script reads completed searches; Find Trade Ideas explicitly calls the existing authenticated `/api/trades/generate` Recommended workflow. Explore more opens the full Recommended workspace. No provider requests, FOIS regeneration, paid infrastructure, new algorithm or permanent recommendation/history store is introduced.

Completed default-filter searches publish a disposable projection: at most four family-distinct offers, qualified recommendations first, separately supported exploratory offers afterward. ## Evidence, authority and bounds

The existing atomic canonical Market capture is used before recommendation evaluation. Source fingerprints before/after discovery reject intervening publication/ownership/projection changes. Cache identity includes authenticated account/session binding, league/franchise, explicit strategy or canonical default, exact protections/exclusions, semantic roster/pick/player/scoring/Market/strength/evidence inputs, canonical projection publication and evaluator version. Per-offer evaluation IDs are not source IDs. Retrieval-only clocks are excluded from semantic identity; actual source/publication context remains included.

Process-only LRU cache: maximum 24 entries, 2 MiB aggregate, 15-minute maximum age. Restart/eviction/expiry yields a Find invitation. One explicit Home search can run at a time; old cancelled work cannot launch a polling loop. No read/unread state or durable write. Matching completed empty results remain distinct from no matching prepared search. No guarantee of recommendations or four cards.

GET `/api/trades/home-opportunities` uses the existing authenticated ownership boundary and no-store response. Foreign source context is rejected. The existing middleware normalizes a requested front-office query to the controlled franchise; it grants no opponent control. Opaque offer tokens resolve only within the current session/source/strategy/protection cache key, expire with it and cannot resolve foreign-league offers.

## Existing workspace preview, no silent adoption

Explore/Edit enters `/trades/create?front_office=…&home_offer=…`. After authenticated workspace initialization and saved draft restoration, it resolves the scoped offer and invokes the existing `previewOffer`. Current draft/strategy/protections remain unchanged until explicit Adopt. Keep Original retains the existing draft; adopted exact assets survive reload. New explicit navigation may preview another idea without erasing a previously adopted draft. Expired/changed offers return a truthful unavailable message; older pending responses cannot supersede newer workspace/strategy intent. Existing locks and target policies remain enforced.

Home uses the saved league-specific strategy cookie and current proposal protections without writing either. No mandatory strategy/partner/position setup. With no explicit strategy, the existing evaluator's supported default/window policy applies; Home does not impose contend/rebuild intent.
