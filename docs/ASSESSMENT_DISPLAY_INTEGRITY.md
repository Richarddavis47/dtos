# Assessment context and retained projection display integrity

Release: v1.21.36 / build 2136. Baseline: v1.21.35 / build 2135,
`60b4fca3398c05cf4ff5e0dbcd8eacf395e62bf2`.

## Assessment contract

The current session strategy is selected intent. An offer's evaluated strategy,
package, ownership binding, evaluation provenance and source generations are
assessment evidence. Changing the former does not certify the latter.

Rendered offer controls capture a bounded structured assessment context when the
result is rendered. Preview carries that context into its proposal and Adopt uses
that same identity. Neither action writes shared strategy. The client reconciles
shared intent before Preview/Adopt and after an asynchronous response, before
admitting that response. Old rendered offers remain browsable with a retained,
not-revalidated qualification. Preview and adopted assessment show original and
current selected strategies together. Recommendation, rationale, major drawback,
exploratory qualification and evidence remain intact. Only completed compatible
evaluation replaces the assessment. Reload retains the existing conservative
not-revalidated contract. Keep Original does not change the package.

No ranking, recommendation thresholds, construction, canonical Market pricing,
locks, source identities or strategy-cookie write policy are changed.

## Independent display compatibility

A scoring-compatible publication can contain an incompatible display method.
The canonical decoder applies a read-only display qualification to retained rows
whose method differs from `sleeper-web-sequential-number-tofixed2-qualified-v2`.
It preserves canonical points, publication/source identity and old method/value
as provenance. It withholds the old display subtotal and exposes the existing
canonical league-scored Sleeper value with an explicit exact-display-unverified
explanation. My Team, dossier, projection fragment and matchup rows disclose it.
Stored publications and original source evidence are not rewritten.

This conservative rule also qualifies old explicit-bonus/non-TE displays until
supported republishing establishes the current display contract. Fresh current
publications keep their established behavior. No coefficient, raw statistic,
canonical calculation or player projection model changes. A failed refresh does
not revive the old subtotal. No backfill or successful refresh is required for
safe reading. Missing canonical points remain unavailable; real zero remains zero.

## Architecture and limits

Only existing canonical publications, session cookies, bounded proposal context
and read-side presentation are used. No new persistent tables, database, history,
archive, preference store, provider calls, polling or storage migration. Repeated
reads and unchanged publications are tested for no durable growth. The existing
2 GiB release resource gates remain unchanged.

The controlled TE example establishes canonical/display-contract mismatch; it
cannot establish actual live Sleeper UI parity. Raw live Sleeper parity and
physical-device acceptance require independent evidence. Unrelated deeply expanded
archive/provider disclosures are covered by existing journeys, not the retained
projection qualification probe.
