# Retired automated visual infrastructure

This system was retired in v1.13.6 by explicit product decision. Do not run capture,
relay, archive or publication commands from older revisions of this document.
Historical release assets remain immutable; no new visual publication is required.

Shared semantic inspection, projection correctness, accessibility and lightweight
browser journeys remain supported. See [validation architecture](VALIDATION_ARCHITECTURE.md)
and [Live Product Inspection](LIVE_PRODUCT_INSPECTION.md).
