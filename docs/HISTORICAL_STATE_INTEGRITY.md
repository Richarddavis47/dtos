# Historical evidence integrity — v1.21.66

The historical state producer previously summed any nearest checkpoint's
`normalized_value`, even when the checkpoint could not prove canonical Market
units. It also treated a nonempty final roster as complete historical ownership.
Neither proves an admissible historical valuation or a complete decision roster.

## Shared admission

`historical_intelligence/price_admission.py` admits only the existing canonical
0–1000 external Market index, supported source/provider membership, nonempty
source/context identity, known normalization and comparison methodology, supported
format semantics, finite in-range numbers and timezone-aware decision-eligible
observation/knowledge/publication clocks. Underlying provider rows must agree
with canonical provider membership, normalization and numeric units; enclosing
metadata cannot confer compatibility on native or future evidence. It does not
normalize raw provider currency or use
current Market. Legacy opaque methods remain preserved but unavailable for this
calculation. Genuine zero is admitted. Incompatible contexts cannot be summed.
Older-than-seven-day quotes remain numeric with the established temporal-confidence
qualification; they cannot establish a historical competitive-window label.
Missing pick prices are no longer replaced by an assumed 1,000-unit value.
Admitted 0–1000 prices are mapped explicitly to the existing classifier's 0–100
input scale, rather than inheriting a provider-native 10,000-unit divisor.

## Reconstruction coverage

Transaction-period acquisition, roster-anchor time and observed event order are
separate dimensions. Missing acquisition periods, incomplete movement records,
unknown anchor clocks or unresolved ordering qualify ownership and cap state
confidence at the existing 40-point limited-evidence boundary. Source acquisition
is not inferred from roster size or observed event count. Unavailable optional
families leave independent facts readable. Partial roster membership is explicitly
qualified in derived lineup interpretation and cannot produce a supported overall
historical Process grade or competitive-window classification. Exact observed
trade and original-franchise pick facts remain accessible.

Coverage in the asset graph now distinguishes structural integrity from supported
transaction acquisition; structural validity alone no longer produces overall
`complete`. An observed-empty acquired period is different from an absent period.
No claim is made that acquired buckets prove a provider never omitted an event.

## Downstream and persistence boundaries

The existing FOIS preparation-time reference adapter uses the same Market admission
and carries structured state coverage. Unsupported windows do not become a manager
window preference through the literal string `unavailable`. New state/transaction
method identities distinguish corrected calculations. Warm state reuse follows the
existing immutable Market publication generation and history revision.

No source records or retained historical grades are changed. Historical FOIS grades
remain **RETAINED / NOT REVALIDATED**. Test-only disposable grade computation checks
handoff/preservation; it does not revalidate live grades. There is no new schema,
archive, permanent analytical state or provider fetching. Record/state cache bounds
remain 512/4096; source-coverage summaries have a 128-entry temporary bound.

## Acceptance boundaries

Focused controls exercise native 100/10,000 units, canonical positives/zero, missing
identity, mixed contexts, future/knowledge clocks, stale observations, missing
transaction coverage and uncertain anchors. Captured Day Traders/Arkham sources
exercise the Dart/Fannin transaction, exact picks, actual retained publishers,
HTTP coverage, source replacement, warm Market revision and unchanged read hashes.
These are controlled source/HTTP facts, not independent Scout or live historical
grade acceptance. Physical iPhone/Safari and human usability remain separate.
